## 要回答的问题
用户问过"声音克隆需不需要算力"。IndexTTS2 跑 GPU，但克隆本质是特征提取，可能 CPU 也能跑（慢）。本 Spike 从 **GPU 侧** 给出真数据（CPU 侧对照归 DEV-A，另行派）。

## 必须产出真实证据（子房硬性要求，缺一不可）
1. **硬件**：显卡型号、显存、CUDA 版本
2. **模型**：IndexTTS2 版本 + 来源
3. **耗时**：克隆一段声音的真实耗时（秒）
4. **资源**：显存/内存峰值
5. **稳定性**：连跑 3 次成功率
6. **质量**：克隆音色与目标音色的相似度（主观 + 客观，附音频路径）

## 结论标记（三选一，必须明确）
- `FEASIBLE-LOCAL`：GPU 本地能跑，质量可用
- `FEASIBLE-CLOUD-ONLY`：本地跑不动或质量差，只能云端 API
- `INFEASIBLE`：现阶段都不行

## 关键边界（子房 D-015）
- **Voice Clone（声音克隆，GPU）与 Standard TTS（现成音色，CPU）是两个不同 Capability**，本 Spike 只测 Voice Clone，别和标准 TTS 混。
