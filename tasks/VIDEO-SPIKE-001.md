## 要回答的问题
甲方核心功能"讲到霸王龙直接呈现它如何攻击/战斗的完整画面"是**文生视频**。这个 12G 显卡本地能不能跑、跑得动、画质能不能用——这是本 Spike 要给出真答案的。

## 验证对象（选 1-3 个实测）
候选：CogVideoX / Seedance / 可灵本地档 / 其他开源文生视频模型

## 必须产出真实证据（子房硬性要求，缺一不可）
1. **硬件**：显卡型号、显存、内存、驱动版本、CUDA 版本
2. **模型**：版本号 + 下载来源
3. **耗时**：生成一段 N 秒视频的真实耗时（秒）
4. **资源**：显存峰值、内存峰值
5. **稳定性**：连跑 3 次，报成功率
6. **质量**：产出视频能否用于教学画面（主观 + 客观，附样片路径）

## 结论标记（三选一，必须明确）
- `FEASIBLE-LOCAL`：12G 本地能跑，质量可用
- `FEASIBLE-CLOUD-ONLY`：本地跑不动或质量差，只能走云端 API
- `INFEASIBLE`：现阶段都不行

- 不硬编码具体模型，结论供 Provider 接缝决定
